# Ahmad Amirul Hafiz — Portfolio

A clean, responsive developer portfolio built with HTML, CSS, and JavaScript. It includes dark/light mode, responsive navigation, scroll animations, project cards, experience, achievements, and contact information.

## Files

- `index.html` — Main portfolio page
- `style.css` — Complete styling and responsive design
- `script.js` — Dark mode, mobile menu, animations
- `profile.jpg` — Profile image
- `resume.pdf` — Downloadable résumé

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files directly to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then click **Save**.
6. Wait one to three minutes and open the generated GitHub Pages link.

## Before publishing

Update the placeholder GitHub and LinkedIn links in `index.html`, and replace the example project cards with your real project names, screenshots, descriptions, and repository links.
